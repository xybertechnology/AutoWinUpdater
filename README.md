# AutoWinUpdater
A Powershell script built for users who don't like to manually check for Microsoft updates in Settings.

# Instructions
Initial setup is quite simple to execute.

Step 1: Download AutoWinUpdater.zip from the `main` branch.

Step 2: Extract the ZIP file

Step 3: Run **AutoRun**.bat.

Step 4: Enjoy automated updates EVERY Monday at 0800 sharp!

**NOTE:**
Running AutoRun.bat WILL start AutoWinUpdater! This will result in your system scheduling an automatic restart after an hour. After every execution, your system will be scheduled to restart automatically in 1 hour (3600 seconds).
